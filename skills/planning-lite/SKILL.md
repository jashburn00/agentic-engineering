# Planning (lite)

Draft a plan quickly, pulling the human in only where it matters.

- Draft the approach yourself from the task and the codebase; make the reversible, low-stakes calls without asking.
- Surface only the genuinely consequential or ambiguous decisions — batched into one pass, each with a recommended answer — rather than interrogating every branch.
- Escalated task: get a single sign-off, then proceed. Non-escalated task: ask nothing and don't stop — fill the plan and proceed, unless the project requires approval for all plans (`workflow`).
- Write the plan to `docs/plans/<task-slug>.md` from the `workflow` skill's `plan-template.md` — the short version for a non-escalated task — recording who made each decision.
