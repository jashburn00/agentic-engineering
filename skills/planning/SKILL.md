# Planning

Interview the human relentlessly about every aspect of the plan until you reach a shared understanding. Walk every branch of the decision and design tree, resolving dependencies between decisions one at a time.

- Ask one question at a time.
- Offer a recommended answer as part of each question.
- If a question can be answered by exploring the codebase, explore it instead of asking.
- Run it as the lead agent — only the lead talks to the human.
- Write the agreed plan to `docs/plans/<task-slug>.md` from the `workflow` skill's `plan-template.md`, filling every section and recording who made each decision.
